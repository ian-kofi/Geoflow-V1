# GeoFlow live demo

A node-based geospatial workflow app: drag nodes onto a canvas and connect them to fetch data, run spatial
analysis and produce a finished map.

Source code, documentation and validation: https://github.com/ian-kofi/Geoflow-V1

This Space builds the latest version from GitHub. The free hardware sleeps when idle, so the first visit can
take a minute to wake up. Results are deleted after a few hours.
